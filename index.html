RRebuildReconstruct a contact-rich world and derive the criterion from one demonstration.
EEchoAccept the world only if it reproduces the demonstration kinematically and dynamically.
SSelf-improveAn agent edits control code on randomized layouts; candidates are adopted by paired evaluation.
EExecuteThe frozen program runs on the physical robot with no agent and no human in the loop.
TTransferHand the same world and criterion, unchanged, to other embodiments.

Skill reuse across embodiments

How much controller code travels with the task

For every task, each robot's controller is compared function by function with the other robots' controllers for the same task. Libraries all five robots share (perception, Cartesian io, the demo-derived scorers) are not counted.

Minder runs 5 of the 8 xTrainer controllers byte for byte (apple, cubes, tower, mug, drawer); the other 3 come from LIFT2 with only the robot layer swapped. XLeRobot's new code is the single-swing gripper grasp and the planning changes a 5-DoF arm needs. G1 was written by a separate agent in its own module set: same skills, almost no shared code. Per task, 7 to 11 perception and motion primitives are called by all five robots.
